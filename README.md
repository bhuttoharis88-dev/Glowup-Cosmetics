## Image Management Guidelines
1. **File Naming Conventions**: Use descriptive names (e.g., `product-name.jpg`) and avoid spaces. Use hyphens or underscores as separators.
2. **File Formats**: Use PNG for graphics with transparent backgrounds and JPG for photographs to balance quality and file size.
3. **Image Optimization**: Optimize images using tools like TinyPNG or ImageOptim before uploading to reduce file size while maintaining quality.
4. **Image Dimensions**: Follow the specified dimensions for images in use cases to ensure coherence across the site.
5. **Accessibility**: Include alt text for all images describing their content for better accessibility.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/bhuttoharis88-dev/Glowup-cosmetics.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Glowup-cosmetics
   ```
3. Install necessary dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   npm start
   ```
