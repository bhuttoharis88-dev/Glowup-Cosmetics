# Image Management Guidelines

## Directory Structure
- Organize images into separate folders based on their use (e.g., `product_images`, `banner_images`, `blog_images`).
- Maintain a consistent folder hierarchy to ease navigation and management.

## Naming Conventions
- Use descriptive names that reflect the content of the image (e.g., `red-lipstick-matte.jpg`).
- Employ a naming format that includes the date and a version, if applicable (e.g., `2026-02-23-product-red-lipstick-v1.jpg`).
- Avoid spaces and special characters; use hyphens or underscores instead.

## Format Guidelines
- Preferred formats: JPG for photographs, PNG for images with transparency, and SVG for logos and icons.
- Avoid using GIFs unless necessary (e.g., for animations).

## Optimization Tips
- Compress images to reduce file size while maintaining quality (use tools like TinyPNG or ImageOptim).
- Use the appropriate resolution—higher resolutions for retina displays (e.g., 2x) and standard resolutions for web.
- Consider lazy loading images that are off-screen to improve page load times.

## Accessibility Requirements
- Use alt text to describe the content of images for screen readers.
- Ensure sufficient contrast between image elements and the background for visibility.
- Avoid text in images when possible, as it may not be readable by all users.

## CDN Integration
- Use a Content Delivery Network (CDN) to host images for faster loading times.
- Ensure images are properly cached for improved performance.

## Image Upload Checklist
1. Verify the directory structure is followed.
2. Check naming conventions for consistency.
3. Ensure proper file format is used.
4. Optimize image size and resolution before upload.
5. Add appropriate alt text.
6. Test image loading speed after integration with the page.
